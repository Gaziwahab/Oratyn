# Glossary

| Term | Meaning |
|---|---|
| Engineering Room | A small group session focused on a technical topic or scenario. |
| Session | A specific instance of an Engineering Room with participants, phases, messages, and a lifecycle. |
| Scenario | A prompt that gives context, constraints, and an engineering problem to reason about. |
| Discussion Protocol | The sequence of phases and participant actions in a session. |
| Structured Contribution | The initial individual response to a prompt before open discussion. |
| Cross-questioning | A phase where participants ask clarifying or challenging questions about contributions. |
| Open Discussion | A less constrained conversation after the structured phases. |
| Host | The user or moderator responsible for facilitating a session. |
| Moderator | A trusted role that can manage sessions and community safety. |
| AI Evaluator | A server-side AI workflow that generates formative feedback from session evidence. |
| Evidence Reference | A link to a real message or artifact supporting an evaluation statement. |
| Rubric | A defined set of criteria used to assess a contribution. |
| Competency | A skill area such as debugging, system design reasoning, or technical explanation. |
| Competency Observation | A dated, evidence-backed signal about a user's performance in one competency. |
| Confidence | How well the available evidence supports an evaluation or competency observation. |
| Next-practice Recommendation | A suggested topic or scenario chosen from the user's goals, evidence, and prerequisites. |
| Skill Passport | A future shareable view of evidence-backed competencies; not part of MVP. |
| P0 / P1 / P2 | MVP-critical / next release / later priority. |
